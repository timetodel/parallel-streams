# Русская версия скилла

Полный перевод `parallel-streams` на русский: сам скилл, справочники, шаблон задания и шаблон
настройки. Ставится вместо английской версии в проектах, где вкладки разговаривают с владельцем
по-русски.

Версия соответствует английской: **1.10.0**. При обновлении английской версии этот каталог
обновляется тем же изменением — расхождение версий здесь означает, что перевод отстал.

## Что здесь лежит

```
localization/ru/parallel-streams/
├── SKILL.md                       переведён
├── references/                    переведены все четыре справочника и блок правил
├── coordination/                  русская механика канала согласования (не перевод, а живой оригинал)
└── scripts/render_map.py          общий с английской версией, перевода не требует
```

**Механика канала (`coordination/`) здесь русская по происхождению**, а не переведённая: сообщения
инструмента, сторожа и установщик писались сразу по-русски, и английская версия в корне репозитория —
её перевод, а не наоборот. Обновлять её надо здесь, а в английскую версию переносить переводом.

**Сборщик схем** (`scripts/render_map.py`) — код, он общий. Его сообщения об ошибках английские
и такими остаются: они разбираются в справочнике `references/diagram-rules.md`.

## Как поставить в проект

Скопировать каталог `parallel-streams` целиком в `.claude/skills/` проекта:

```powershell
Copy-Item "<путь к этому репозиторию>\localization\ru\parallel-streams" `
          "<корень проекта>\.claude\skills\" -Recurse -Force
```

Дальше как обычно: настройка `.parallel-streams.md` в корне проекта (шаблон —
`parallel-streams/coordination/templates/profile.md`), и, если нужен канал согласования вкладок,
его установщик: `pwsh .claude/skills/parallel-streams/coordination/install.ps1`.

## ‼️ Что в переводе не переводится

**Заголовки разделов настройки остаются английскими** — `## Isolation`, `## Tests`, `## Review`,
`## Persistent rules` и остальные. Скилл ищет их по этим именам: переведённый заголовок означает
раздел, которого для скилла не существует, и молча включается значение по умолчанию. Переводится
содержимое разделов.

По той же причине не переводятся: имена файлов, ключи запуска сборщика схем, команды канала
согласования и обозначения потоков на схеме (`S1`, `S2`).

## Словарь

Термины держатся одинаковыми по всем файлам — иначе задания, собранные из разных справочников,
начинают называть одно разными словами.

| Английский | Русский |
|---|---|
| session | вкладка |
| stream | поток |
| brief | задание |
| map | карта |
| wave | волна |
| subagent | субагент |
| worktree | рабочее дерево |
| pull request | запрос на слияние |
| review gate | проверка перед слиянием, разбор изменений |
| escalation | усиленный режим |
| profile | настройка проекта |
| persistent rules file | постоянный файл правил |
| the person, the user | владелец |
| coordination channel | канал согласования |
| claim / release a stream | объявить / сдать поток |
